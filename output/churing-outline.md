## 第1ラウンド：物真似マシン登場！
（まえがき / 第3章後半 / 第5章）

### 見せ場
「万能」の正体はスペック自慢じゃなく、**物真似できること**。

### ビート
1. **専用マシン時代**  
   てりー：昔の計算機械は歯車で、特定の計算しかできない。用途を変えるには歯車自体を組み替える必要があった（まえがき）。
2. **チューリングの斬新さ**  
   てりー：1930年代、ソフトを入れ替えて1台にさまざまな計算をさせる発想は斬新だった（まえがき）。
3. **単能 vs 万能**  
   てりー：ゲームやブラウザは「単能チューリング・マシン」（＝ある目的のソフト）。  
   コンピュータは「万能チューリング・マシン」。ゲームだけできてもコンピュータではない（第3章）。
4. **物真似の定義**  
   てりー：万能である＝物真似ができる。他のチューリング・マシンの動作を代理実行できる（第5章）。

### よーたの問い（例）
- 「万能って、頭がいいってこと？ それとも真似がうまいってこと？」
- 「それって結局、今のパソコンでソフト切り替えてる話？」

### ハイピー補充（本の外）
- スマホにアプリを入れる＝同じ箱で役割を変える、くらいの日常たとえ
- ※てりーが「本にはそこまで書いていない」と言ったあとだけ

### ラウンド締めの決めゼリフ案
**てりー**  
本の言い方だと、万能とは物真似ができること。

**よーた**  
じゃあ勝ち確じゃん。……次で崩れるんでしょ？

## 第2ラウンド：解けない問題の逆襲
（第4章・決定問題 / 停止問題）

### 見せ場
万能マシンでも、**止まるか止まらないかを事前に判定する機械は作れない**。

### ビート
1. **ヒルベルトの勝負**  
   てりー：数式が証明できるかを機械的に判断できるか。できればヒルベルトの勝ち、できなければ負け——本は「数学との勝負」とも書く（第4章）。
2. **Yes/No問題**  
   てりー：決定問題＝YesかNoだけで答える問題。計算できるかは、最終的にこの形に帰着できる（第4章）。
3. **止まらないマシンがある**  
   てりー：チューリング・マシンには、実行しても止まらないものがある（第4章）。
4. **嘘つきパラドックス**  
   てりー：「クレタ人は嘘つきだ」とクレタ人が言う——仮定すると矛盾する古典的パラドックスを経由（第4章）。
5. **停止判定マシンの自滅**  
   てりー：「止まるか止まらないかを実行前に判定するマシン」を仮定すると、自分自身を入力したとき矛盾する。よってそんな判定マシンは作れない（第4章）。
6. **オチ**  
   てりー：ヒルベルトの決定問題への答えは「できない」。未来のコンピュータでも、性能が上がっても状況は変わらない、と本は強調する（第3章・第4章）。

### よーたの問い（例）
- 「待って、できないって証明できるの？ バグってるだけじゃなく？」
- 「それ、AIが超賢くなっても無理ってこと？」

### ハイピー補充（本の外）
- 「終わらない検索を、終わる前に見抜けるか」みたいなたとえ
- ゲーデルへの一般説明は、てりーが本の範囲（本はゲーデルにも触れる）を優先。本外の現代AI論はハイピー

### ラウンド締めの決めゼリフ案
**よーた**  
真似はできる。でも“止まるかどうか”は分からない。

**ハイピー**  
つよい……負け方まで理論になってる。

## 最終ラウンド：解けなさが武器になる時
（第6章・計算量 / P・NP / 暗号）

### 見せ場
「絶対できない」の隣に、**できるけど現実的に終わらない**がある。  
その難しさが、暗号の盾になる。

### ビート
1. **できる/できないの次**  
   てりー：計算できても短時間でできない問題がある。そういうときは別の方法を探す、と本は整理する（第3章の効果の話〜第6章へ）。
2. **クラスPとNP**  
   てりー：P＝（ざっくり）現実的な時間で解ける側。  
   NP＝答えを見ればチェックしやすいが、解くのは大変、という側（第6章の議論）。
3. **P=NPか？**  
   てりー：PとNPは同じか？ は大問題として残る（第6章）。
4. **逆転オチ：暗号**  
   てりー：素因数分解など、「NPであるゆえに安全である暗号」という話がある（第6章）。  
   解けなさ／難しさが、守る側の武器になる。

### よーたの問い（例）
- 「解けない問題があるのは最悪ニュースだと思ってたけど、守る側には都合いい？」
- 「それ、パスワードの話につながる？」

### ハイピー補充（本の外）
- 鍵を開けるのは大変、合ってるか見るのは簡単、くらいのたとえ
- 現代の具体サービス名は出しすぎない（本の論理を濁さない）

### ラウンド締めの決めゼリフ案
**てりー**  
本では、NPであるゆえに安全である暗号、と書かれている。

**よーた**  
解けない側が、最後に勝つのか……。
