# 台本：ハッキングってどうやるの！？

みなさんは、映画やドラマで、ハッカーが黒い画面に緑の文字を打ち込んでハッキングするシーンを見たことはありませんか。そこでハッカーは、何を、どうやっているのでしょうか。

先に一度だけ注意します。他人のサイトやパソコンに、許可なく攻撃を仕掛けるのは犯罪です。今日話すのは、同じ仕組みを知っておくための話です。

ハッキングとは、コンピュータやネットワーク、プログラムの仕組みを調べ、想定外の動きや穴を見つける行為を指すことが多いです。この言葉自体は、最初から悪事だけを指すわけではありません。許可を取ったうえで穴を探し、直すために報告する人たちもおり、ホワイトハッカーと呼ばれることがあります。反対に、許可なく侵入したり、盗んだり、壊したりする側は、ブラックハッカーなどと呼ばれることがあります。

フィッシングと呼ばれる詐欺や、本物に見せかけた偽サイトは警戒が必要です。フィッシングとは、本物の案内に見せかけて、相手からパスワードや確認コードなどを出させる詐欺です。ただ、今回の話には詐欺は含めません。特定の相手や特定のシステムを狙うのが、ここで言うハッキングです。不特定多数にランダムにばらまいてだますのが、フィッシングなどの詐欺です。

ここでは、特定のターゲットを狙うハッキングを、三つの軸に分けます。一つ目は、特定のアカウントのパスワードを狙うことです。二つ目は、特定の相手の端末の操作権限を奪うことです。三つ目は、特定のサービス側のシステムの穴を狙うことです。

一つ目は、特定のアカウントのログインです。メールアドレスが分かれば、残るのはパスワードです。攻撃する側は、よく使われる定番パスワードを上から試すことがあります。これを辞書攻撃と呼びます。過去の大規模流出で使われていたパスワードをまとめたリストがあり、使われやすさの順になっているものもあります。上位には、数字の連なりや、パスワードという英単語そのもの、アイラブユーのような短い定番が来ます。

別のやり方として、どこかで流出したメールとパスワードの組を、別のサービスでも次々試すものがあります。辞書攻撃がよくある候補を当てるのに対し、こちらは実在した組を横流しします。どちらも、パスワードそのものを狙います。

二つ目は、特定の相手のスマホやパソコンです。狙うのは、ログイン画面への入力ではなく、端末の操作権限そのものです。狙った相手に請求書だという添付を開かせたり、公式っぽい偽アプリを入れさせたりして、端末の中で勝手に動く状態を作ります。操作権限を握ると、ブラウザに保存したパスワードなどを抜き、本人のつもりで別サービスへログインできます。不特定多数に暗号化するプログラムをばらまく話は、今回の特定ターゲットのハッキングからは外します。

三つ目は、特定のサービスのシステムの穴です。その前に、普通のログインを押さえておきます。多くのウェブサービスは、ログイン時にデータベースへ問い合わせます。データベースとは、登録情報を表の形で保管しておく仕組みです。その問い合わせに使う言葉がSQLで、データベースを動かすための言語です。登録済みユーザーの表から、入力されたメールとパスワードが一致する行を探し、見つかればログインできます。

攻撃する側は、メール欄などに、奥のSQL文の意味をずらす文字列を入れることがあります。この系統をインジェクション、つまり注入と呼び、代表例がSQLインジェクションです。データの文字列として閉じるべきところを途中で終わらせ、いつも成立する条件を足し、後ろのパスワード照合などを無視させます。すると、一致確認が効かなくなり、表の先頭に近い人などで通ってしまう場合があります。画面にはSQL文は見えません。奥ではこういう文が組まれているはずだ、と推測して試します。

システムの穴はSQLだけではありません。更新されていないソフト、初期パスワードのままの管理画面、外に開いた入口なども突かれます。ニュースで脆弱性を攻撃されたと聞く話の多くは、この系統です。脆弱性とは、システムに残った隙や欠陥のことです。

三つの軸を見たところで、映画でよくあるシーンに戻ります。特定のビルのシステムに入り込み、防犯カメラの映像を差し替える、という場面です。あれは、特定のビルのカメラ系統に、今見た三つの軸のどれか、または組み合わせで入り込んでいる、と読めます。

ビルの防犯カメラは、映像を集める録画装置や、監視用の管理画面、モニターにつながっていることが多いです。狙うのはレンズより、映像が集まっている側のシステムです。パスワードを狙う場合は、監視システムの管理用アカウントに定番や流出した組を試します。端末の操作権限を奪う場合は、監視室のパソコンや管理担当者の端末を握り、そこから操作します。システムの穴を狙う場合は、カメラや録画装置、管理ソフトの更新されていない穴から入ります。

管理側に入れたあと、ライブ映像の代わりに用意した映像を繰り返し流す、というのがドラマの差し替えに近いです。モニターに出す映像だけを切り替える、カメラを止める、録画を残さない、といった操作もあります。やっていることは、特定ターゲットの監視システムに入り、表示や録画の制御を握ることです。

ここでホワイトハッカーの話に戻ります。ホワイトハッカーは、許可を取ったうえで、今見てきたような入り方をわざと試し、穴を先に見つけます。この作業をペネトレーションテストと呼びます。守りたい側が、攻撃する側と同じ地図を持つための作業です。そのために、練習用の環境や穴を確認する道具が表で手に入ることもあります。似た道具は裏にも出回るため、隠すと守る側だけが試せなくなります。公開して試せるようにした方が、穴は塞がりやすい、という考えです。

映画の黒い画面の奥では、特定のターゲットに対して、パスワード、端末、システムの穴のどれかを狙う作業が起きていることが多いです。ハッキングという言葉自体は悪事だけを指すわけではありません。不特定多数をだます詐欺は、今回は含めていません。やり方は、知らなくても困りません。知っていると、何が起きているのかが分かります。
