# 台本：ハッキングってどうやるの！？

みなさんは、映画やドラマで、ハッカーが黒い画面に緑の文字を打ち込んでハッキングするシーンを見たことはありませんか。監視モニターが切り替わり、暗証番号が次々と当たり、誰かのパソコンが遠隔から動かされる。そうした場面は、何度も繰り返し出てきます。そこでハッカーは、何を、どうやっているのでしょうか。

先に一度だけ注意します。他人のサイトやパソコンに、許可なく攻撃を仕掛けるのは犯罪です。今日話すのは、同じ仕組みを知っておくための話です。

ハッキングとは、コンピュータやネットワーク、プログラムの仕組みを調べ、想定外の動きや穴を見つける行為を指すことが多いです。ニュースでは悪い行為として聞こえることが多いですが、ハッキングという言葉自体が、最初から悪事だけを指すわけではありません。

許可を取ったうえで穴を探し、直すために報告する人たちもいます。こうした人たちをホワイトハッカーと呼ぶことがあります。反対に、許可なく侵入したり、盗んだり、壊したりする側は、ブラックハッカーなどと呼ばれることがあります。同じ調べ方でも、許可があるか、何のために使うかで、立ち位置が分かれます。

一方で、フィッシングと呼ばれる詐欺や、本物に見せかけた偽サイトは、インターネット上で警戒する必要があります。フィッシングとは、本物の案内に見せかけて、相手からパスワードや確認コードなどを出させる詐欺です。ただ、今回の話には詐欺は含めません。整理の軸は単純です。特定の相手や特定のシステムを狙うのが、ここで言うハッキングです。一方、不特定多数にランダムにばらまいてだますのが、フィッシングなどの詐欺です。偽サイトも、広く人を釣る入口として使われることが多く、今回のハッキングの話からは外します。

ここでは、特定のターゲットを狙うハッキングを、三つの軸に分けて方法をお話しします。一つ目は、特定のアカウントのパスワードを狙うことです。二つ目は、特定の相手の端末の操作権限を奪うことです。三つ目は、特定のサービス側のシステムの穴を狙うことです。やり方を知らなくても別に困りません。一方で、やり方を知っていると、画面の向こうで何が起きたのかが分かります。

一つ目の軸では、特定のアカウントのログインを狙います。ログイン画面では、メールアドレスが分かれば、残るのはパスワードです。攻撃する側は、よく使われる定番パスワードを上から試すことがあります。これを辞書攻撃と呼びます。名前の通り、候補を辞書のように並べ、上から順に当てていくやり方です。

過去の大規模流出で使われていたパスワードをまとめたリストがあり、使われやすさの順になっているものもあります。上位には、数字の連なりや、パスワードという英単語そのもの、アイラブユーのような短い定番が来ます。人が自分で覚えられるパスワードは弱いことが多く、そのため定番から当てに行けます。映画では暗号を一瞬で解くように見えますが、現実では、当たりやすい候補から試していることも多いです。

別のやり方として、どこかで流出したメールとパスワードの組を、別のサービスでも次々試すものがあります。辞書攻撃がよくある候補を当てるのに対し、こちらは実在した組を横流しします。どちらも、パスワードそのものを狙っている点では同じです。特定の人のアカウントに入りたい、という目的に対して、秘密そのものを試している、と整理できます。

二つ目の軸では、不特定多数をだますのではなく、特定の相手のスマホやパソコンを狙います。狙うのは、ログイン画面にパスワードを入力させることではなく、その端末の操作権限そのものです。端末を握れれば、ログイン画面の外側から、中の情報や操作に触れられます。

たとえば、狙った相手に請求書だという添付を開かせたり、公式っぽい偽アプリを入れさせたりして、端末の中で勝手に動く状態を作ります。操作権限を握ると、ブラウザに保存したパスワードなどを抜き、本人のつもりで別サービスへログインできます。別の型では、その端末上の写真や書類を開けなくし、解除するなら金を払え、と画面に出します。これをランサムウェアと呼びます。ファイルを人質のように扱えなくするプログラムです。フィッシングサイトが不特定多数を釣る詐欺なのに対し、ここは特定の端末を握るハッキングです。

三つ目の軸では、特定のサービスのシステムの穴を狙います。その前に、普通のログインが何をしているかを押さえておきます。多くのウェブサービスは、ログイン時にデータベースへ問い合わせます。データベースとは、登録情報を表の形で保管しておく仕組みです。その問い合わせに使う言葉がSQLです。ツール名ではなく、データベースを動かすための言語です。登録済みユーザーの表から、入力されたメールとパスワードが一致する行を探し、見つかればログインできます。たとえで言うと、引き出しの棚から、名前と合い言葉が一致するものだけを開ける作業です。

攻撃する側は、メール欄などに、普通の文字ではなく、奥のSQL文の意味をずらす文字列を入れることがあります。この系統をインジェクション、つまり注入と呼び、代表例がSQLインジェクションです。仕組みは三段です。データの文字列として閉じるべきところを途中で終わらせ、いつも成立する条件を足し、後ろのパスワード照合などを無視させます。すると、一致確認が効かなくなり、表の先頭に近い人などで通ってしまう場合があります。利用者の画面にはSQL文は見えません。それでも奥ではだいたいこういう文が組まれているはずだ、と推測して試します。見えない内部を想定して、入力という穴から意味をずらす。それがこのやり方です。

システムの穴は、SQLだけではありません。更新されていないソフト、初期パスワードのままの管理画面、外に開いた入口なども突かれます。ニュースで、脆弱性を攻撃された、と聞く話の多くは、この系統です。脆弱性とは、システムに残った隙や欠陥のことです。映画の天才がゼロから発明するばかりではなく、既知の穴の放置が多い、と考えてよいです。

三つの軸を見たところで、ドラマや映画でよくあるシーンに戻ります。よくあるのは、特定のビルのシステムに入り込み、防犯カメラの映像を差し替える、という場面です。黒い画面に緑の文字が続いたあと、監視モニターだけが偽の映像になる、という流れです。あれは魔法ではなく、特定のビルのカメラ系統というターゲットに対して、今見た三つの軸のどれか、または組み合わせで入り込んでいる、と読めます。

ビルの防犯カメラは、単独で完結しているのではなく、映像を集める録画装置や、監視用の管理画面、それを映すモニターにつながっていることが多いです。差し替えたい側が狙うのは、レンズそのものより、映像が集まっている側のシステムです。つまり、特定の建物の監視まわり、というはっきりしたターゲットがあります。不特定多数へのばらまきではありません。

入り方は、三つの軸に対応します。パスワードを狙う場合、監視システムの管理用アカウントに、定番パスワードや流出した組を試す、という形になります。端末の操作権限を奪う場合、監視室のパソコンや、管理担当者の端末を握り、そこから録画ソフトや管理画面を操作する、という形になります。システムの穴を狙う場合、カメラや録画装置、管理ソフトの更新されていない穴から、管理画面へ入る、という形になります。映画では一瞬で終わりますが、現実では、どの機器が映像を握っているか、誰が管理しているか、を特定するところから始まります。

管理側に入れたあと、ライブの映像の代わりに、あらかじめ用意した映像を繰り返し流す、という操作が、ドラマの差し替えに近いです。廊下は空いているように見え続け、実際には別のことが起きている、というあの構図です。あるいは、モニターに出す映像だけを別のソースへ切り替える、カメラを止める、録画を残さない、といった操作もあります。見た目は目立ちますが、やっていることは、特定ターゲットの監視システムに入り、表示や録画の制御を握ることです。冒頭の黒い画面は、その管理画面やコマンド操作を、映画用に分かりやすく見せている、と考えてよいです。

ここで、前に触れたホワイトハッカーの話に戻ります。ホワイトハッカーは、許可を取ったうえで、わざと今見てきたような入り方を試し、穴を先に見つけます。この、許可のもとで侵入を試す作業を、ペネトレーションテストと呼びます。守りたい側が、攻撃する側と同じ地図を持つための作業です。パスワードを試す、端末の操作権限を奪う、システムの穴を突く。そうした入り方を、許可の範囲で先に確認します。

そのテストを行うために、練習用の環境や、穴を確認するための道具が、表で手に入ることもあります。初めて聞くと、そんなものを配って大丈夫なのか、と感じるのが普通です。ただ、似た道具は裏にも出回ります。隠すと、守る側だけが試せなくなります。そのため、都合が悪く見えるやり方でも、公開して試せるようにした方が、穴は塞がりやすい、という考えがあります。今日、攻撃側の視点で話してきたのも、攻める手順を勧めるためではなく、守る穴を見つけるためです。

映画の黒い画面の奥では、特定のターゲットに対して、パスワード、端末、システムの穴のどれかを狙う作業が起きていることが多いです。防犯カメラの差し替えも同じで、ビルの監視システムという特定ターゲットに入り、表示や録画の制御を握る話です。ハッキングという言葉自体は、悪事だけを指すわけではありません。ホワイトハッカーのように、守りのために穴を探す人たちもいます。フィッシングや偽サイトのような、不特定多数をだます詐欺は、今回のハッキングの話には含めていません。やり方は、知らなくても困りません。知っていると、何が起きているのかが分かります。
