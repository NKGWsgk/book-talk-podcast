# 台本：シュレディンガーの猫の生死は箱を開ける前から決まっていた。

シュレディンガーの猫という思考実験をご存じでしょうか。小さな世界の量子の説明を猫にまで広げると、猫は生きている状態と死んでいる状態の重ね合わせになってしまう、とされます。それはおかしいのではないか、と問うのがこの思考実験です。

確かに、箱を開ける前の猫が、生きている状態と死んでいる状態の重ね合わせになっているとは考えにくいです。一方で、現代物理では、量子力学において重ね合わせが起きていることも事実です。では、この思考実験には、どこに解釈のずれが起きているのでしょうか。

量子力学は、おもにごく小さな世界の振る舞いを扱う理論です。量子は、現実の世界では実感しにくい動き方や性質を持っています。量子の世界では、観測するまで、電子が右の穴も左の穴も通ったように振る舞う、原子核が壊れたとも壊れていないとも言える、といった説明が使われます。その状態を、重ね合わせと呼びます。重ね合わせとは、複数の可能性が同時に成り立っている、と量子の世界で説明される状態です。

そして量子の世界では、観測すると、その重ね合わせが解けて、状態が一つに定まる、と説明されます。ここで言う観測は、人が何となく眺めることではなく、結果を一つに確定させる行為です。放射性物質の崩壊も、量子の世界の話です。問題になるのは、観測で状態が定まる、という説明を、猫のような大きなものにまで広げるかどうかです。

一九三五年、エルヴィン・シュレディンガーが提示した思考実験が、シュレディンガーの猫です。密閉した箱の中に、猫と、放射性物質と、放射線を計測するガイガーカウンターと、毒の仕組みを置きます。一定時間のうちに放射性物質が崩壊するかどうかは確率的です。崩壊をガイガーカウンターが検出すると、毒の仕組みが働き、猫は死にます。検出しなければ、猫は生きたままです。この装置が示そうとしたのは、小さな世界の説明を猫にまで広げると、日常の感覚と合わなくなる、という点です。

ここでよく出てくる説明は、箱を開けるまで、猫は生きている状態と死んでいる状態の重ね合わせにある、というものです。この説明では、人間が箱を開けて中を見ることが観測であり、その瞬間に生死のどちらかへ定まる、とされます。聞き手が覚えるのは、開けない限り決まらない、という一文になりやすいです。

量子の世界では、観測すると状態が定まる、ということは、すでに共有されています。ずれは、その観測を、人が箱を開けることだと置いたところにあります。人が箱を開けた瞬間に初めて生死が定まるとすると、開けるまで猫は生きている状態と死んでいる状態の重ね合わせのままです。日常の感覚では、それは考えにくいです。箱を開ける行為は、人間が結果を知ることです。しかし、猫の生死を分けているのは開ける手だとすると、不都合が残ります。

では、観測とは何かを問い直します。量子の話で重要な観測は、人が箱を見て確かめることそのものではありません。結果を一つに確定させる行為です。

では、放射線を計測するガイガーカウンターの計測も、観測ではないのか、となります。カウンターは、崩壊という小さな出来事を、電気信号のような大きな応答へ変えます。人が箱を開ける前に、すでに計測は起きています。観測を計測まで広げるなら、開ける手だけが特別ではなくなります。

さらに言うと、観測という言葉そのものが狭くなります。箱を組んだ時点で、そこにはすでに空気があり、温度があり、振動があります。猫のような大きなものを置く世界では、そうした周囲との関わりが避けられません。空気や温度、振動との関わりでも、重ね合わせは解け、状態は一つに定まります。人が見ることだけが確定の条件ではありません。だから、箱を開ける前から、量子としての曖昧さは残っていません。開けるのは、すでに定まった結果を人間が知る行為です。

ここで言う確定とは、哲学の最終決着ではありません。猫を重ね合わせのまま保つ条件が、箱を組んだ時点でもう成り立っていない、という意味です。箱を開けることは、その条件を初めて壊す行為ではありません。

このずれは、猫の箱だけのものではありません。ウランなどの放射性崩壊も、もともと小さな世界の過程です。原子力発電では、その過程が熱や発電という日常の結果へつながるように装置が組まれています。現場の扱いは、原子炉が壊れている状態と壊れていない状態の重ね合わせを、誰かが見るまで待つ、というものではありません。計測器の値、温度、出力といった日常の指標として扱い、制御します。周囲の世界に置かれた時点で、重ね合わせの話としては扱われていない点で、猫の箱と同じ系統です。

私たちは、崩壊そのものを目で見ていません。見ているのは、熱や電気や、計測器の針といった、すでに日常の結果へ移ったあとの姿です。だから量子の話が、箱を開ける特別な瞬間として残りやすい、という側面があります。猫の箱も、周囲との関わりを見ずに開ける行為だけを見ると、同じ見え方になります。

では、量子の性質を、日常の装置の中で残したまま扱うことはできないのか。その試みの一つが量子コンピュータです。量子コンピュータは、重ね合わせや干渉といった量子の性質を、計算の部品として使おうとします。猫の箱では、空気や温度、振動といった周囲との関わりが状態を定めます。量子コンピュータでは逆で、計算に使うあいだは、その関わりをできるだけ減らします。熱や振動など、量子性を壊す要因を抑え、制御できる時間だけ重ね合わせを保つ必要があります。計算の途中で、ほしい情報だけを取り出し、それ以外の量子性を不用意に壊さないよう設計する、という難しさもあります。

猫の箱は、周囲の世界に置かれた時点で、量子の重ね合わせを保たない側の話です。量子コンピュータは、周囲との関わりを抑えて、量子の性質を壊さずに使い続ける側の話です。同じ量子の話でも、周囲との関わりで状態が定まるのを受け入れるのか、それを避けるのかで、狙いが逆です。だから量子コンピュータは難しい、という話にも、猫の箱の話がつながります。難しさの本体は、計算の見た目ではなく、空気や温度、振動に邪魔されずに量子の性質を保つ設計にあります。

シュレディンガーの猫で大事なのは、箱を開ける瞬間そのものではありません。箱を組んだ時点で、空気や温度、振動などによってすでに状態が定まっていることです。その時点で、猫を生きている状態と死んでいる状態の重ね合わせとして保つ話にはなっていません。箱を開ける前から、量子としての状態はすでに定まっています。開けるのは、その結果を人間が知る行為です。
